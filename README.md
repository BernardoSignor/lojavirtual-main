# StockBuilderS

Nome do aluno: Bernardo Signor

## Tema/proposta do sistema

O projeto consiste no desenvolvimento de um sistema web para gerenciamento de estoque e vendas de uma distribuidora de bebidas.

O sistema permitira controlar produtos, categorias, clientes, fornecedores, movimentacoes de estoque e pedidos de venda atraves de uma interface administrativa e tambem de uma area publica para consulta de produtos.

## Situacao atual do projeto

O projeto ja possui autenticacao com login, registro e perfil de usuario.

Tambem possui cadastro e listagem de produtos e tipos de produtos. A tela inicial publica lista produtos cadastrados no banco de dados, exibindo apenas produtos com preco e quantidade maior que zero.
